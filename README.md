## 简介:模仿《动物森友》狸语风格的语音合成算法，轻量，低延迟，流式文本，支持自动识别中/日/英。支持流式文字与实时打字生成。

- **在线应用体验地址**：[https://clarance.top/apps/animalese-voice-mix](https://clarance.top/apps/animalese-voice-mix)


## 核心算法架构

从输入的文本到生成连续音频波形，核心管线思路；

```text
 文字源
        │
        ▼
 Step1：三语语境路由与音韵拆解（Tokenizer）
    ├─ 中日语种判别：检测分句内假名特征自动归属中日汉字读音。
    ├─ 中文分支（zh）：查表映射汉字拼音与 1~4 声调/轻声，将语法虚词标记为可优先舍弃的弱读单元（weak）
    ├─ 英文分支（en）：基于 1.6 万词美式音标词典切分音节、复辅音、主重音与轻声词尾辅音微单元，未登录词按元音核拼读
    └─ 日文分支（ja）：结合词组与动词/形容词活用训读词干转为假名音拍，处理拗音合并、助词音变（は→wa / へ→e）、长音与促音留白
        │
        ▼
 Step2：双时钟解耦调度与分级滞后丢字（VoiceClock）
    ├─ 文字时钟：按字符视觉阅读步长独立推进（拉丁字母 0.45 步、假名 1.48 步、日文多拍汉字按音拍数自适应步进，遇标点附加停顿）
    ├─ 语音时钟：限制最大音节触发密度（英语词尾微单元按 1.88 倍紧贴前元音尾端，日语按 0.95 倍等拍推进），遇标点或促音插入精确静音间隙
    └─ 滞后追赶决策（lag = 候选发声时刻 - 当前揭示时刻）：
         ├─ lag > 1 × maxLag：优先舍弃标记为 weak 的轻声虚词与助词
         ├─ lag > 2 × maxLag：舍弃句中普通音节以快速收敛音画延迟
         └─ 句尾双字保护：强制豁免每个分句末尾最后两个音节，确保听感收束完整自然
        │
        ▼
 Step3：8 点半音滑音轮廓求解（Prosody Solver）
    ├─ 语种基础语调：中文映射四声曲率；英文抬升重读音节并压低非重读弱元音；日文生成“低起→跃升→高平→核后回落”的东京起伏包络
    ├─ 句法与情绪修饰：叠加自然句调倾角（Downdrift）、确定性微抖动（±0.2 st），以及问号上扬（+3 st）、感叹提音扩幅、省略号微沉
    └─ 曲线离散化：在单音节时窗内插值求解 8 个控制点，按十二平均律换算为实时播放倍率曲线与目标基频曲线
        │
        ▼
 Step4：平直采样精灵与三路并联共振峰混音（Web Audio Pipeline）
    ├─ 采样切片通路：从离线统一拉平至 364Hz 的 .ogg 精灵声库截取对应音节，通过 playbackRate 曲线无冲突注入目标语调
    ├─ 数学合成通路：锯齿波 + 三角波双声门源驱动三路并联带通滤波器（F1 / F2 / F3 含复韵母滑移），音头叠加清辅音窄带噪声脉冲
    └─ 等功率总线塑形：按正余弦等功率曲线融合双声源，经低通暖度滤波与动态压缩稳压防削波后输出
```

## 关键算法设计拆解

### 1. 离线语音语调归一化

传统拼接式动森语音若直接对自然朗读录音做变速变调，素材原有的声调走向会与运行期施加的语调相互干涉（例如拿降调录音强行上扬会产生怪异扭曲）。

本项目在离线构建阶段通过 Praat PSOLA 对中（407 个）、英（525 个）、日（115 个）全部 **1,047 个基础音节与辅音微单元**执行统一预处理：
- 英、日采用载体句中段风格向量与促音静音闭锁提取法消除单字母音无声化，并对清辅音字头与稳态母音核做双区独立时域整形；
- 将基频曲线彻底拉平至恒定基准频率 $f_{\text{bank}} = 364\text{ Hz}$；
- 将有效发音时长规整至紧凑窗口（母音单元约 `105 ms – 115 ms`，英语词尾微单元约 `64 ms`），并采用平滑包络线性限幅均衡响度以消除削顶失真；
- 中、英、日各自保留原生母语发音人音色，混排时按音节动态路由声库，消除跨语种口音违和感。
- 如果把语调直接烤死在离线音频里，声库体积会成倍膨胀：
光普通话约 400 个基础音节，乘以阴平、阳平、上声、去声、轻声就要存近 2000 条切片；
若还要区分疑问语气、感叹语气、高音小动物与低音大叔声线，音频包会大到不适合网页即点即用。
离线只存一份无声调的平直基础音节（三语加起来不到千个切片，每个 .ogg 仅几百 KB），运行时只需动态改变采样播放倍率，同一个 ma 切片既能捏出四声变化，也能随时在 150 Hz 低沉嗓音和 420 Hz 幼态嗓音之间无极切换。

### 2. 双时钟解耦与句尾保护丢字模型

在对话框打字机推进或流式文本输入场景中，文字揭示速率往往远高于舒适的音节发声速率上限：
- 若为每个字符强行即时叠加发声，音节高度重叠会导致齿音糊成一片噪音；
- 若严格排队逐字念完，文字早已显示完毕而语音仍拖尾数秒。

`VoiceClock` 将**文字视觉揭示时钟**与**语音声学排期时钟**彻底解耦：设当前时刻为 $t_{\text{now}}$，上一音节起点为 $t_{\text{last}}$，标点静音释放时刻为 $t_{\text{free}}$，最大语速为 $u_{\text{max}}$，则下一候选发声时刻与滞后量为：

$$t_{\text{cand}} = \max\!\left(t_{\text{now}},\; t_{\text{last}} + \frac{1}{u_{\text{max}}},\; t_{\text{free}}\right), \qquad \text{lag} = t_{\text{cand}} - t_{\text{now}}$$

当滞后量突破阈值时，调度器按语言学重要度分级舍弃音节（先舍弃“的、了、吗、は、を”等语法功能词，严重滞后时再抽稀句中实词），但**始终锁死保留每个分句末尾的最后两个音节**。这恰好吻合人类快速说话时“吞略句中轻读音节、清晰落定句尾重音和语气”的真实听觉心理。

### 3. 多语种 8 点半音韵律求解

`solvePitchContour` 为每个获准发声的音节计算长度为 8 的等距半音偏移序列 $\Delta s_k$（$k \in \{0,\dots,7\}$）：
- **普通话声调曲线**：阴平（`[+0.8, +0.8]` 高平）、阳平（`[-0.6, +1.6]` 中升）、上声（`[-1.0, -1.8, -0.6]` 降折）、去声（`[+1.6, -1.2]` 全降）、轻声（`[-0.8, -0.8]` 短促低落），弯曲强度受声调系数线性缩放。
- **英语词重音对比**：主重读音节叠加半音抬升与振幅增益，非重读弱音节（Schwa）下沉 `-0.45 st`，形成鲜明的轻重交替节奏。
- **日语东京式高低音拍**：按文节（Bunsetsu）首拍低起（`low`）、次拍跃升（`rise`）、拍核维持（`high`）及核后助词回落（`fall` / `drop`）生成折线包络，并对礼貌体句尾（如 `ます` / `です` 的 `す`）保持自然降落。
- **十二平均律映射**：将总半音偏移映射为采样播放倍率 $r_k$ 与合成器振荡频率 $f_k$：

$$r_k = \frac{f_{\text{base}}}{f_{\text{bank}}} \cdot 2^{\Delta s_k / 12}, \qquad f_k = f_{\text{base}} \cdot 2^{\Delta s_k / 12}$$

### 4. 三路并联共振峰与等功率混音

除采样声源外，`formant.ts` 实现了一套零外部音频依赖的声学合成模型：
- **双波形声门激励**：`0.68` 锯齿波提供丰富高次谐波以支撑共振峰滤波，`0.42` 三角波补充温暖基频厚度；
- **口腔元音共振器**：三组并联二阶带通滤波器分别追踪目标韵母的第一、第二、第三共振峰（$F_1, F_2, F_3$），复韵母（如 `ai`、`iao`、`uang`）在音节周期内执行起止频率指数滑移，并随角色基频高低自动缩放等效声道长度；
- **清辅音瞬态爆破/摩擦**：针对塞音（`b/p/d/t/g/k`）、擦音（`f/s/sh/x/h`）与塞擦音（`z/c/zh/ch/j/q`），在起始 `14 ms – 28 ms` 注入特定中心频率的带通白噪声脉冲以塑造清晰字头；
- **等功率混合（Equal-Power Crossfade）**：混合比例 $\alpha \in [0, 1]$ 通过 $g_{\text{sample}} = \cos(\frac{\pi}{2}\alpha)$ 与 $g_{\text{formant}} = \sin(\frac{\pi}{2}\alpha)$ 分配增益，确保 $g_{\text{sample}}^2 + g_{\text{formant}}^2 = 1$，在采样与合成声源间切换时总声能恒定不塌陷。

## 目录结构

```text
animalese-voice-mix/
├── src/                      # 零依赖核心语音合成算法源码
│   ├── tokenizer/            # 多语种音韵拆解子系统
│   │   ├── english.ts        # 英语词典重音映射与元音核拼读回退算法
│   │   ├── japanese.ts       # 日语汉字转假名、促音/拗音规整与东京音拍核求解
│   │   └── shared.ts         # 公共字符集判定与数据结构
│   ├── audio/                # Web Audio 声学管线子系统
│   │   ├── bankStore.ts      # 三语精灵声库与读音词典管理、按需解码缓存
│   │   └── audioPipeline.ts  # 等功率双核混音、低通暖度滤波与动态压缩总线
│   ├── tokenizer.ts          # 分句语种路由与三语分词编排入口
│   ├── clock.ts              # VoiceClock 双时钟排期、标点停顿与滞后丢字算法
│   ├── prosody.ts            # 8 点半音滑音轮廓与十二平均律倍率求解器
│   ├── formant.ts            # 三路并联共振峰与辅音噪声脉冲数学合成器
│   ├── engine.ts             # AnimaleseEngine 核心引擎编排门面
│   ├── presets.ts            # 典型声学参数预设配置
│   ├── types.ts              # 核心算法类型与数据结构定义
│   └── index.ts              # 模块统一导出入口
├── speech/                   # 离线平直化三语音节精灵库与读音词表
│   ├── zh.ogg / zh.json      # 普通话 407 音节 364Hz 精灵音频与时间切片索引
│   ├── en.ogg / en.json      # 英语 525 音节（含复辅音与词尾辅音微单元）364Hz 精灵音频与索引
│   ├── ja.ogg / ja.json      # 日语 115 音拍 364Hz 精灵音频与时间切片索引
│   ├── zh-lexicon.json       # 汉字至拼音与声调映射表
│   ├── en-lexicon.json       # 常用英语词至音节与主重音映射表
│   └── ja-lexicon.json       # 日语常用汉字词组与单字假名读音映射表
├── scripts/                  # 离线声库与词典生成脚本
│   ├── build-voice-bank.py   # 基于 Kokoro + Praat PSOLA 生成 364Hz 平直三语精灵库
│   └── build-lexicons.py     # 基于开源词典构建英/日前端读音映射表
└── tests/
    └── engine.test.ts        # 三语分词、双时钟滞后丢字与滑音轮廓单元测试
```
